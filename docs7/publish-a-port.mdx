---
title: "Publish a port"
---

[Publish](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Publish) maps a host port to a container port on a container or a service. [Expose](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Expose) records the container port and does not bind the host. A job does not take `Publish`.

```go
import . "github.com/aptd3v/containerkit/pkg/kit"

svc := NewService(
    Name("api"),
    Image("alpine:latest"),
    Publish(
        Protocol(TCP),
        HostIP("127.0.0.1"),
        HostPort(8080),
        ContainerPort(80),
        Mode(PortHost),
    ),
    Expose(8081, TCP),
)
```

`Publish` is a port mapping. Publishing the compose project as an OCI artifact is [Compose.PublishOCI](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Compose.PublishOCI).

`Mode` inside `Publish` is `PortIngress` or `PortHost`. The same setter inside [Deploy](/resources-and-deploy) is `Replicated` or `Global`. A Swarm job uses `svcmode.ReplicatedJob` or `svcmode.GlobalJob`.
