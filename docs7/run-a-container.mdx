---
title: "Run a container"
---

[Run](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Run) dials [Connect](/bring-a-compose-file-up), creates the container, starts it, and closes the client. It returns the [Created](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Created) value from create, including when start fails. [Client.Run](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Client.Run) does the same on a client you already have.

```go
import (
    "context"

    . "github.com/aptd3v/containerkit/pkg/kit"
)

func start(ctx context.Context) (Created, error) {
    return Run(ctx,
        Name("web"),
        Image("nginx:latest"),
        Publish(Protocol(TCP), HostPort(8080), ContainerPort(80)),
    )
}
```

[Container.Create](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Container.Create) returns the id when you need it before start. [Container.Start](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Container.Start) takes that id.

```go
import (
    "context"

    . "github.com/aptd3v/containerkit/pkg/kit"
)

func create(ctx context.Context, cli *Client) (string, error) {
    worker := NewContainer(Name("worker"), Image("alpine:latest"))
    created, err := worker.Create(ctx, cli.Engine())
    if err != nil {
        return "", err
    }
    if err := worker.Start(ctx, cli.Engine(), created.ID); err != nil {
        return created.ID, err
    }
    return created.ID, nil
}
```

[PullImage](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#PullImage) and [BuildImage](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#BuildImage) take the Engine from the same client. Both return only an error. The pull stream is read to the end inside `PullImage`. A [Logger](/logging) is the progress stream.

```go
import (
    "context"

    . "github.com/aptd3v/containerkit/pkg/kit"
)

func images(ctx context.Context, cli *Client, log *Logger) error {
    if err := PullImage(ctx, cli.Engine(), "alpine:latest", Log(log)); err != nil {
        return err
    }
    return BuildImage(ctx, cli.Engine(),
        NewDockerfile().From("alpine", "latest"),
        Image("app:dev"),
        Log(log),
    )
}
```
