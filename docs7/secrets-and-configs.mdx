---
title: "Secrets and configs"
---

[Secret](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Secret) and [FileConfig](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#FileConfig) attach a project secret or config to a service or a job. Declare them with [AddSecret](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#AddSecret) and [AddFile](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#AddFile), or with [Compose.WithSecret](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Compose.WithSecret) and [Compose.WithFile](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#Compose.WithFile). [FromFile](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#FromFile) is the file contents.

```go
import . "github.com/aptd3v/containerkit/pkg/kit"

compose := NewCompose("app",
    AddSecret(Name("db"), FromFile("./db_password")),
    AddFile(Name("app"), FromFile("./app.yaml")),
).WithService(NewService(
    Name("api"),
    Image("alpine:latest"),
    Secret(Name("db"), Target("/run/secrets/db")),
    FileConfig(Name("app"), Target("/etc/app/config")),
))
```

`FromFile` is file content. [File](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#File) is another compose YAML path on [ImportFile](/import-and-export). [DockerfilePath](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#DockerfilePath) is a Dockerfile path inside [Build](/build-and-dockerfile). [OutputFile](https://pkg.go.dev/github.com/aptd3v/containerkit/pkg/kit#OutputFile) is an export archive.
